문의 전에 가장 많이 걱정하는 것들.

시안 받고 나면, 언제부터 진짜 개발이 시작돼요?
1차 시안은 화면 스케치와 최소 기능을 구현한 화면입니다. 화면 흐름 · 용어 · 빠진 업무를 표시해 주시면 반영한 뒤, ‘기능 · 권한 확정서’와 정식 견적서로 범위를 고정합니다. 확정하고 계약금 50%를 내신 날부터 시작해 7일차에 2차 시안, 14일차에 3차 마무리본을 받아 보십니다. 그 전까지는 비용이 없습니다.
어떻게 14일 안에 되나요?
밥만 먹고 이것만 만듭니다. 계약하면 그 회사 전담으로 붙어서 다른 일을 섞지 않습니다. 화면 설계는 계약 전에 1차 시안으로 이미 끝나 있고, 반복되는 기본 기능(로그인 · 권한 · 엑셀 · 알림)은 검증된 구성을 그대로 씁니다. 그래서 14일은 오로지 우리 회사 업무에만 씁니다. 7일차에 2차 시안으로 중간 결과를 직접 확인하시고, 범위가 커서 더 걸리는 경우엔 계약서에 실제 일정을 먼저 적어 드립니다.
우리 회사는 어느 규모로 만들게 되나요?
TYPE A(연 매출 ~15억)는 가장 답답한 업무 하나부터 — 예) 출퇴근 기록 → 급여 계산, 화면 묶음 4~5개. TYPE B(15억~80억)는 따로 놀던 업무를 한 흐름으로 — 예) 예약 → 배정 → 노쇼 알림 → 정산, 화면 묶음 6~7개 · 역할별 권한 · 자동 알림. TYPE C(80억~)는 본사 · 지점 · 부서를 하나로 — 예) 지점 보고 → 비교 → 결재, 화면 묶음 8~10개 · 통합 리포트 · AI 에이전트. 세 TYPE 모두 14일 완성이 기준이고, 금액은 상담이 끝난 뒤 견적서로 안내합니다.
기본으로 뭐가 포함돼요?
TYPE별로 화면 묶음(A 4~5개 · B 6~7개 · C 8~10개), 화면 수정(A 3회 · B 6회 · C 9회), 무상 개선 기간(A 1주 · B·C 1개월), 대표·직원 권한 분리, 엑셀 내보내기, 온라인 교육과 녹화본이 들어 있습니다. 매달 내는 돈은 AI · 서버 이용료 하나이고 사용 인원 기준으로 정해집니다.
직원들이 잘 쓸 수 있을까요? 교육은요?
로그인 하나로 역할에 맞는 화면만 열립니다 — 대표는 전체, 점장은 매장 업무, 직원은 본인 근무와 할 일. 쓰던 습관도 살립니다. 자사 스키스쿨에서는 상담사가 카톡 예약 문구를 그대로 붙여넣으면 스케줄이 채워지는 방식으로 운영하고 있습니다. 교육은 전부 온라인(화상 · 녹화 영상 · 매뉴얼)이며 TYPE별 횟수가 견적에 들어 있습니다.
견적은 어떻게 나와요? 나중에 돈이 더 붙지 않나요?
시작 금액은 회사 규모(연 매출 · 직원 수 · 사용자 수를 종합)로 정해지고, 그 안에 화면 묶음이 기본 포함됩니다. 그보다 많은 기능 · 외부 연동 · 자료 이관을 더할수록 금액이 올라갑니다. 규모가 조금 다르다고 금액이 크게 뛰지 않도록 구간 없이 이어지게 계산합니다. 추가 비용은 확정 범위에 없던 신규 기능을 요청하실 때만 생기며, 금액과 일정을 먼저 안내하고 승인하셔야 진행합니다. VAT 별도.
제가 말한 걸 제대로 알아들었는지 어떻게 알아요?
말씀하신 내용은 기획서에 ‘요청’과 ‘ATZ 추천’으로 구분해 적습니다. 업무 흐름마다 지금 방식 · 막히는 점 · 프로그램이 하는 일 · 사람이 확인할 일을 나눠 보여 드리고, 모르는 항목은 확인 질문으로 남깁니다. 고치고 싶은 부분은 말로 요청하면 새 버전으로 다시 정리되고, 이전 버전도 남습니다.
고쳐 달라고 할 때마다 돈 내야 하나요?
오류는 합의한 기능이 다르게 동작할 때로, 무상 개선 기간(A 1주 · B·C 1개월)엔 무제한, 그 뒤엔 유지보수 가입 시 무상으로 고칩니다. 화면 · 문구 조정은 TYPE별 수정 3 · 6 · 9회 안에서 처리하고(요청 한 묶음 = 1회), 다 쓴 뒤 추가 수정은 견적서에 적힌 기준으로 진행합니다. 선택 유지보수에는 매달 수정 횟수가 들어 있습니다(요청 한 묶음 = 1회, 남은 횟수는 이월되지 않음). 신규 기능은 범위 밖이라 추가 견적 후 진행합니다. VAT 별도.
